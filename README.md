# Fenêtre

Dashboard plein écran pour une TV Hisense VIDAA : planète noire, horloge, liste du jour et objectifs lus depuis Google Sheets.

Fond : Mercure, plaines volcaniques du nord (MESSENGER). NASA / Johns Hopkins APL / Carnegie Institution of Washington, domaine public, PIA19415.
Polices : Michroma et Geist (licence OFL).

Le code qui pilote la TV n’est pas dans ce dépôt.
